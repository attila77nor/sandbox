# Build tools for the Analytika concepts

Plain Node scripts (Node 22, no dependencies; `site-shot.cjs` needs Playwright).
Run them from anywhere; paths resolve relative to this folder.

- `site-build.mjs` writes the nine clickable pages and `preview.html` to `../concepts/site/` (the dark serif look with the Galton-board stand-in). Running it again reproduces the committed files byte for byte.
- `library-wall.mjs` writes `../concepts/library/index.html`: a drawn library wall with five chalkboards. It is a stand-in for the photograph that will replace it. All formulas and curves on the boards are correct mathematics.
- `figures.mjs` holds the five maths figures (survival curve, Lorenz curve, star graph, decision tree, logistic curve), the illustrative Gompertz law and the area and page lists.
- `lib.mjs` splits `../assets/logo/logo.svg` (converted from the supplied PDF) into mark and wordmark symbols that can be recoloured with CSS variables.
- `art.mjs` draws the Galton board stand-in.
- `site-shot.cjs` takes screenshots and click-tests the site (`SHOTS=<folder> node site-shot.cjs`).
- `explore-r1-*.mjs` write round 1 of the exploration to `../concepts/explore/`: four new directions (`oslo`, `tabell`, `trekant`, `tetthet`), each a home page and a People page, plus `index.html` (`explore-r1-index.mjs`). `explore-shared.mjs` holds what they share. `explore-r1-shots.cjs` takes the screenshots into `concepts/explore/img/` (`MOBILE=1` also takes 390 px full-page shots).
- `explore-r2-vegg.mjs` writes the three home pages built on `../assets/photo/tavler.jpg` (`vegg-hvit`, `vegg-marine`, `vegg-zoom`); `explore-r2-shots.cjs` takes their screenshots. Board positions on the photograph are measured in pixels at the top of the script.
- `explore-bundle.mjs` writes `../concepts/explore/preview.html`: every exploration page and the photograph in one self-contained file, with tabs for the seven directions. Pages that are not designed yet open a plain stand-in with a Back button. Run it after the other `explore-*` scripts. Send or open this one file; the single page files need their sibling folders.
- `explore-r3-forside.mjs` writes `../concepts/explore/forside.html`, the landing page with the photograph over the whole screen that dissolves into white and four grey rows; `explore-r3-shots.cjs` takes its screenshots. Rebuild `preview.html` with `explore-bundle.mjs` afterwards (the landing is its first tab).
- `photo-neutral.py IN OUT [--grain STD] [--lift GAMMA] [--scale N]` (Python, needs Pillow and numpy) turns a warm-toned black-and-white photograph into neutral greys, adds a little clarity and film grain. `--grain 2.2` matches the first whiteboard photograph. Run it on the final photograph at its final size, so the grain stays fine.
- `explore-r3-forside.mjs` now writes three landing pages, one per photograph: `forside` (first whiteboard photo), `forside-rom` (the Oslo room, not dimmed, title at the bottom right) and `forside-kontor` (the open-plan office, dimmed). All three are tabs in `preview.html`.
- `oversikt.mjs` writes `../oversikt.html`: one self-contained file that shows every page, photograph and inspiration image we have, grouped by page type, with thumbnails; a click opens the page inside the file and its links keep working. The list of what to show lives in `oversikt-data.mjs` (add a page there, with a section and a status). `oversikt-thumbs.cjs` takes the thumbnails into `../concepts/thumbs/` (run it first when a page has changed; needs Playwright and python3 with Pillow). Order: the `explore-*` scripts, then `explore-bundle.mjs`, then the thumbnails, then `oversikt.mjs`.
