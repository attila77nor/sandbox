# Inspirasjon og referanser

Alle skjermbilder som er delt i designsamtalen, samlet på ett sted. Bildene ligger i den rekkefølgen de ble delt. Logoen ligger i `../assets/logo/` (PDF og SVG).

## 1-dagens-nettside
Skjermbilder av dagens analytika.no og GitHub-repoet, som kilde til fakta (ikke tekst).
- `01-github-repo-homepage.png`: repoet Analytika-AS/homepage (Next.js).
- `02-forside-hero-og-tjenester.webp`: forsiden med fjellbildet og de fire tjenestene.
- `03-pricing-and-analytics.webp`: tjenestesiden for pricing.
- `04-ventures-stillinger-footer.png`: Analytika Ventures, ledige stillinger og footer.

## 2-referanser-runde-1
Første inspirasjon. «Den brune» (nr. 5) var den som falt best i smak, selv om fargen er feil. Tre av bildene er helsides-skjermbilder som er presset sammen og har lav oppløsning.
- `01-vantra-moerk-hero-uskarp-figur.webp`: mørk hero med uskarp figur i bevegelse, stor tekst.
- `02-lys-side-hav-og-sand-komprimert.webp`: lys side med hav og sand.
- `03-moerk-side-komprimert.webp`: mørk side.
- `04-moerk-hero-fjell-og-fugler.webp`: mørk hero med fjell, tåke og fugler; serif-overskrift.
- `05-den-brune-komprimert.webp`: den brune siden.
